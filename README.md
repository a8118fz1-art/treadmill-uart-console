# 履帶跑步機 UART 工程上控台

以瀏覽器（Web Serial API）直連下控（Yade MCU 按鍵板）的開發測試工具。
本程式扮演 **上控（Android / TFT 主機）** 角色。

協定整理見 [docs/PROTOCOL.md](docs/PROTOCOL.md)，來源為
`履帶TFT_UART通訊碼按鍵定義-智奇20260724.xlsx`。

---

## 快速開始

一律使用**桌面版 Chrome / Edge**（Web Serial API 僅支援 Chromium 系瀏覽器）。
以下三種開啟方式擇一，功能完全相同：

| 方式 | 做法 | 適用 |
|---|---|---|
| **線上版** | 直接開部署好的網址 | 給廠商測試，零安裝 |
| **雙擊開啟** | 對 `index.html` 按右鍵 → 用 Chrome 開啟 | 已實測可用，不需要任何工具 |
| **本機伺服器** | 雙擊 `serve.bat`，開 <http://localhost:8080> | 開發時改檔案立即重整 |

接著：按「選擇串列埠」挑 USB-TTL 轉換器 → 設定 Baudrate（**9600** 為 A4.00 版，舊版為 1200）→ 按「連線」。

> 沒有硬體時，勾選 **「模擬下控」** 再按連線，會啟用內建的按鍵板模擬器，
> 可完整驗證協定收送、解析、自動回覆與 UI 流程。

### 部署（GitHub Pages）

專案是純靜態前端，無建置步驟，直接從分支發布即可：

Settings → Pages → Source 選 **Deploy from a branch** → 分支 `main`、資料夾 `/ (root)` → Save。
約一分鐘後網址就會出現在同一頁。根目錄的 `.nojekyll` 用來停用 Jekyll 前處理。

### 接線

| USB-TTL | 下控按鍵板 |
|---|---|
| TX | RX |
| RX | TX |
| GND | GND |

3.3V / 5V 準位請先確認，避免直接對接造成損壞。

## 功能

**控制台**
- 速度模式 / 阻力模式切換（切換時自動先送 `0x02` 停機，符合協定規定）
- 啟動 `0x01` / 停機 `0x02`；速度 0.5–20.0 km/h、揚昇 0–20 段、阻力 0–100 段
- 滑桿即時送出運行指令（運轉中，120 ms 節流）
- **下行指令集可切換**：調整時要送 `0x03`/`0x04`/`0x06` 分項設定（實機觀測，預設）
  還是 `0x01` 運行指令帶新值（文件字面）——兩種解讀的爭點見 [PROTOCOL.md §7](docs/PROTOCOL.md)
- 自動回覆機制：收到 `0x03` / `0x04` / `0x06` 後依協定回送 `0x01`
  （預設僅在運轉狀態回覆；停機時回覆會直接啟動機器，需另外勾選）
- 存活訊號 `0x55` 自動輪詢與往返時間量測
- 揚升工程模式 `0xCA`，未收到 `0xC7` 時每 5 秒自動重送

**即時狀態**
- 帶速儀表隨模式切換：速度模式顯示上控下達的設定值 `0x01`，阻力模式顯示下控回傳的即時速度 `0x0C`
  （速度模式下若收到 `0x0C`，記錄會標為協定偏差）
- 累計步數 `0xC0`（增量累加）、心率 `0x09`
- 安全鎖狀態、運轉狀態、下控回應延遲
- 異常面板：E1–E14 中文訊息與故障排除建議
- 通訊統計：收送框數、位元組數、校驗和錯誤、雜訊位元組

**通訊記錄**
- TX / RX 全框十六進位 + 中文解碼，毫秒時間戳
- 篩選（TX / RX / 異常）、暫停、清除、匯出 CSV（含 BOM，Excel 可直接開）
- 手動送框（自動計算校驗和）與原始位元組送出（不補校驗，可測錯誤處理）
- 命令速查表，點擊即帶入手動送框

**下控模擬器**（勾選「模擬下控」時出現）
- 模擬按鍵板動作：START / STOP / 速度・坡度・阻力調整 / 安全鎖 / Hub Reset / Wake Up / 蜂鳴器
- 注入 E1–E14 任一錯誤碼、無速度迴授 `0xD0`
- 注入雜訊位元組，驗證解析器重新同步能力
- 運轉中自動回傳步數、心率，阻力模式下回傳即時速度

```
index.html          介面
css/style.css       樣式
js/protocol.js      協定編解碼（框架組裝、校驗和、串流解析器、命令表、錯誤表）
```

## 協定摘要

```
 ┌──────┬──────┬──────┬──────┬──────┬──────┐
 │ 0xAA │ 0xBB │ CMD  │  D1  │  D2  │ SUM  │
 └──────┴──────┴──────┴──────┴──────┴──────┘
```
`SUM = (0xAA + 0xBB + CMD + D1 + D2) & 0xFF`

| 常用命令 | 意義 |
|---|---|
| `0x01` | 運行（D1 = 速度×10 或阻力段、D2 = 揚昇段） |
| `0x02` | 停機 |
| `0x03` / `0x04` / `0x06` | 下控要求調整速度 / 坡度 / 阻力 → **上控必須回 `0x01`** |
| `0x05` / `0x0A` | 安全鎖斷開 / 合上 |
| `0x09` / `0x0C` / `0xC0` | 心率 / 即時速度 / 步數 |
| `0x55` | 存活訊號（上控問、下控回） |
| `0xCA` / `0xC7` / `0xCB` | 進工程模式 / 回應 / 揚升值 |
| `0xDA`–`0xE7` | 錯誤碼 E1–E14 |

## 注意事項

- Web Serial API 需要安全環境。`https://`、`http://localhost` 與本機 `file://` 都算安全環境（`file://` 已實測可用）；
  但**區網 IP 不行**（例如 `http://192.168.1.20:8080`），Chrome 會直接隱藏 `navigator.serial`，程式會顯示「不支援」橫幅。
- 一個串列埠同時只能被一個程式佔用，測試前請關閉其他終端機軟體。
- 表頭同時標註 9600（A4.00）與 1200（舊版）兩種鮑率，請依實際韌體版本選擇。
- 舊版（20170516）文件的速度範圍為 `0x0A~0xFA`、坡度 `0x00~0x0F`，與 2026 版不同，本工具以 2026 版為準。
