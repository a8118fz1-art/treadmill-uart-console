# 履帶跑步機 TFT ↔ 下控 UART 通訊協定

> 來源：`履帶TFT_UART通訊碼按鍵定義-智奇20260724.xlsx`（工作表：通訊碼）
> 角色：**上控 = Android / TFT 主機**、**下控 = Yade MCU 按鍵板**
> 本 WebApp 扮演「上控」角色。

## 1. 實體層

| 項目 | 值 |
|---|---|
| Baudrate | **9600**（A4.00 版本）／ **1200**（舊版） |
| 格式 | 8-N-1 |
| 流程控制 | 無 |

> 表頭同時標註 `A4.00-UART鮑率:9600` 與 `Baudrate 1200.8.N.1`，實測請依韌體版本切換。
> `TFT 主機有命令才發送一筆命令碼`（非週期輪詢，事件驅動）。

## 2. 框架格式（固定 6 bytes）

```
 ┌──────┬──────┬──────┬──────┬──────┬──────┐
 │ 0xAA │ 0xBB │ CMD  │  D1  │  D2  │ SUM  │
 └──────┴──────┴──────┴──────┴──────┴──────┘
   起始    起始   命令  速度/阻力 揚昇   累加和
```

`SUM = (0xAA + 0xBB + CMD + D1 + D2) & 0xFF`

驗算範例：
- `START` → `AA+BB+00+00+00 = 0x165` → SUM = **0x65** ✓
- `安全鎖合上 0x0A` → `0x16F` → SUM = **0x6F** ✓
- `存活訊號 0x55` → `0x1BA` → SUM = **0xBA** ✓
- `進入揚升工程模式 0xCA` → `0x22F` → SUM = **0x2F** ✓

## 3. 命令表

方向：`↑` 上控→下控、`↓` 下控→上控、`↕` 雙向

| CMD | 名稱 | 方向 | D1 | D2 | 說明 |
|---|---|---|---|---|---|
| `0x00` | START | ↓ | 0x00 | 0x00 | 按鍵板按下 START 通知上控 |
| `0x01` | 運行指令 | ↕ | 速度 `0x05~0xC8` / 阻力 `0x00~0x64` | 揚昇 `0x00~0x14`（阻力模式 `0x00~0x0F`） | 速度值 = km/h × 10 |
| `0x02` | 停機指令 | ↕ | 0x00 | 0x00 | |
| `0x03` | 速度調整指令 | ↓ | 速度 | 揚昇 | 上控收到後**必須回下運行指令 0x01**，下控才會調變頻器 |
| `0x04` | 坡度調整指令 | ↓ | 速度 | 揚昇 | 同上，需回 `0x01` |
| `0x05` | 安全鎖斷開 | ↓ | 0x00 | 0x00 | |
| `0x06` | 阻力調整指令 | ↓ | 阻力 `0x00~0x64` | 揚昇 `0x00~0x0F` | 同上，需回 `0x01`；**切換模式需先停機 `0x02`** |
| `0x07` | Hub Reset | ↓ | 0x00 | 0x00 | 長按 STOP，安卓屏復位觸控屏（SUM 0x6C） |
| `0x08` | Wake Up | ↓ | 0x00 | 0x00 | 待機時按任意鍵喚醒；若為安全鎖，喚醒後仍要再送 `0x05`（SUM 0x6D） |
| `0x09` | 心率 | ↓ | HEART `0x00~0xFF` | 0x00 | |
| `0x0A` | 安全鎖合上 | ↓ | 0x00 | 0x00 | SUM 0x6F |
| `0x0B` | 系統待機 | ↑ | 0x00 | 0x00 | 通知按鍵板：安卓系統已進入待機 |
| `0x0C` | 即時速度回傳 | ↓ | 速度高位元 | 速度低位元 | **僅阻力模式**；速度 = (H×256+L)/10，0.5~50.0 km/h |
| `0x25` | 蜂鳴器短 | ↓ | 0x00 | 0x00 | 新增 |
| `0x26` | 蜂鳴器長 | ↓ | 0x00 | 0x00 | 新增 |
| `0x55` | 存活訊號檢查 | ↕ | 0x00 | 0x00 | 上控發問、下控回同碼（SUM 0xBA） |
| `0xC0` | 步數 | ↓ | 步數高位元 | 步數低位元 | **只傳本次更新量，不累加** |
| `0xC7` | 工程模式回應 | ↓ | — | — | `0xCA` 的回應 |
| `0xCA` | 要求進入揚升工程模式 | ↑ | 0x00 | 0x00 | 若 5 秒內未收到 `0xC7`，重送（SUM 0x2F） |
| `0xCB` | 揚升工程模式-揚升數值 | ↓ | 0x00 | 目前揚升值 | 需拔安全鎖才能離開工程模式 |
| `0xD0` | 無速度迴授 | ↓ | 0x00 | 0x00 | 下控每 0.5 秒送一次，直到安全鎖斷開 |

## 4. 數值換算

| 項目 | 範圍 | 換算 |
|---|---|---|
| 速度（`0x01`/`0x03` D1） | `0x05~0xC8` | `km/h = D1 / 10` → 0.5 ~ 20.0 km/h |
| 揚昇（速度模式） | `0x00~0x14` | 0 ~ 20 段 |
| 揚昇（阻力模式） | `0x00~0x0F` | 0 ~ 15 段 |
| 阻力（`0x01`/`0x06` D1） | `0x00~0x64` | 0 ~ 100 段 |
| 即時速度（`0x0C`） | `0x0005~0x01F4` | `km/h = (D1×256+D2)/10` → 0.5 ~ 50.0 |
| 步數（`0xC0`） | `0x0000~0xFFFF` | `步 = D1×256+D2`（增量） |

> 舊版（20170516）文件的速度/坡度範圍為 `0x0A~0xFA` / `0x00~0x0F`，與 2026 版不同，以本表為準。

## 5. 錯誤碼（`0xDA ~ 0xE7`）

| CMD | 代碼 | 訊息 | 故障排除 |
|---|---|---|---|
| `0xDA` | E1 | 運轉中輸入電壓過低 | 請檢查輸入電源 |
| `0xDB` | E2 | Encoder 異常 | 請檢查 Encoder |
| `0xDC` | E3 | 過載 | 請關電重新開機 |
| `0xDD` | E4 | 直流母線電壓過高 | 請檢查輸入電源 |
| `0xDE` | E5 | 溫度過高保護 | 請檢查散熱風扇 |
| `0xDF` | E6 | 過電流保護 | 請關電重新開機並檢查負載 |
| `0xE0` | E7 | 變頻器過載異常 | 請關電重新開機並檢查負載 |
| `0xE1` | E8 | 卡鍵 | 檢查按鍵有無卡鍵 |
| `0xE2` | E9 | 程式資料異常 | 請關電重新開機 |
| `0xE3` | E10 | 輸入電壓過低 | 請檢查輸入電源（電容電壓低於 197V） |
| `0xE4` | E11 | 過載保護 | 請關電重新開機並檢查負載 |
| `0xE5` | E12 | 馬達過載異常 | 請關電重新開機／檢查馬達 |
| `0xE6` | E13 | 通訊錯誤 | 請檢查線材與接頭 |
| `0xE7` | E14 | 變頻器其他錯誤 | 請檢查下控燈號 |

保留錯誤碼：`0xE8 0xE9 0xEA 0xEB 0xEC 0xED 0xEF 0xF0 0xF1`

> 註：錯誤碼可從 `0xD0~0xEF` 定義；安全開關斷開後再插回按鍵板會重置。
> 新增推力機型的錯誤碼與舊機代碼不同。

## 6. 重要時序規則

1. **調整必須回運行指令**：下控送 `0x03`/`0x04`/`0x06` 後，上控**必須**回 `0x01` 運行指令，下控收到才會調整變頻器。
2. **模式切換要先停機**：速度模式 ⇄ 阻力模式之間切換前，必須先送 `0x02` 停機。
3. **按鍵板不可自行蜂鳴**：只有收到上控的 `0x01` 運行指令才能啟動。
4. **工程模式重送**：送出 `0xCA` 後 5 秒內未收到 `0xC7`，需重送 `0xCA`。離開工程模式須拔安全鎖。
5. **存活訊號**：上控主動送 `0x55`，下控回 `0x55`。
6. **無速度迴授**：下控偵測到無速度時每 0.5 秒送一次 `0xD0`，直到安全鎖斷開。
